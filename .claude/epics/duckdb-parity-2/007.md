# Task: QA close-out — full suites, cell-exact SF=10+SF=100, docs, epic close

## Description

Final task, matching every one of the six prior epics' own close-out
discipline: full suites in all feature combinations, cell-exact
validation at both scales, benchmark re-measurement, CLAUDE.md update,
and an honest before/after write-up in this epic's file — including
which gates were met, which weren't, and why (this program's own house
style never overclaims; "gate not met, residue is named and
program-level" is a normal, acceptable outcome when the evidence
supports it).
