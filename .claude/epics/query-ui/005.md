# Task: Cluster, Tables and SQL console views

## Description

- `#/cluster`: `/cluster` members table (node id, address, flight
  address, ready, last seen, self marker) with a link to each member's
  `/ui`.
- `#/tables`: `/tables` list with expandable column schemas and a
  "query count" column from `/stats.tables`.
- `#/sql`: textarea + mode selector (`auto|1|0`) → `POST
  /sql?format=json`; results grid (first 1,000 rows), elapsed/rows from
  headers, error text on failure, and a link to the detail page via
  `x-qe-query-id`. Ctrl+Enter runs.

## Acceptance Criteria
- [ ] Cluster view renders on a single node and on the 3-process
      testbed.
- [ ] Tables view shows all eight TPC-H tables and their columns.
- [ ] Console runs a query, shows results, and the detail link opens
      the record created by that run.
