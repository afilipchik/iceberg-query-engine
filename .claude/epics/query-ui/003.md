# Task: UI shell, embedded static serving, Overview + Queries list + Query detail views

## Description

`src/distributed/ui/{index.html,style.css,app.js}` embedded with
`include_str!` and served at `/ui`, `/ui/`, `/ui/app.js`,
`/ui/style.css` with correct content types and `Cache-Control:
no-cache`. Hash router, fetch helpers, formatters (bytes, ms, relative
and absolute times), a poller that pauses when the tab is hidden.

Views in this task:
- **Overview** (`#/`): stat tiles from `/stats` (running, qpm, p95,
  error rate, spilled, pool used/max, members, uptime) and the 10
  latest queries.
- **Queries** (`#/queries`): table with state pill, submitted, elapsed,
  rows, peak mem, spill/dist flags, door, SQL preview; N selector,
  text filter, state filter, sortable columns, auto-refresh toggle.
- **Query detail** (`#/query/<id>`): SQL block with copy, status/error
  banner, phase timeline bar (SVG), facts grid, distribution table,
  optimized/physical plan blocks, raw JSON toggle, 404 message.

Light/dark via `prefers-color-scheme`; no external assets.

## Acceptance Criteria
- [ ] `GET /ui` returns HTML; `/ui/app.js` is `text/javascript`;
      `/ui/style.css` is `text/css`; `/ui/nope` is 404.
- [ ] Manually verified in a browser against a node with TPC-H loaded:
      all three views render, deep links work, auto-refresh pauses.
- [ ] No console errors; page works with JS modules on Firefox/Chrome.
