# Task: Fault-injection/differential testing harness

## Description

The prior `spill-join-correctness` epic's own manual repro loop cost
140-291s/trial (pre-fix) or 3-6s/trial (post-fix) and its own "best
remaining hypotheses" list named a downsized synthetic repro as the
single highest-leverage unattempted next step. This task builds that
capability for real, as a reusable, permanent tool: force a spill at
chosen points during build/probe, and differentially compare the result
against a non-spilling reference execution of the identical query
(row-count and/or checksum invariants) — cheap enough to run hundreds of
trials, not tens.

Independent of task 001's outcome — build this regardless, and use it in
task 001 if task 001 hasn't already reached a verdict by the time this
lands (check task 001's status/coordinate rather than assuming strict
ordering).

## Acceptance Criteria

- [ ] A reusable mechanism (a test harness, example binary, or both —
      your call, document it) that can force `SpillableHashJoinExec`'s
      spill path to engage at a chosen, controllable point in build/probe
      (not just "spills or doesn't" based on data size — genuinely
      choosable injection points, matching this program's existing
      `QE_SPILL_CHAOS_FORCE_ABORT`-style precedent from the prior epic's
      own task 001, which should inform but not necessarily be reused
      verbatim).
- [ ] Differential comparison: the same logical query run once with
      forced spilling and once without, results compared (row-count
      and/or checksum — document which and why) — cheap enough that
      hundreds of trials are practical, not tens.
- [ ] Demonstrate real value: run it for real, at real scale, enough
      times to either (a) catch a natural failure this task itself then
      hands to task 001 for root-causing, or (b) build meaningful
      additional confidence in the current 0.34%-ish rate estimate with
      a materially larger trial count than the prior epic's 290.
      Report exactly what happened, honestly, either way.
- [ ] Documented for future use — this should outlive this epic as a
      standing tool, matching the prior epic's own
      `.scratch/spill_join_repro/repro.sh` precedent (or supersede it,
      if this is strictly better — your call, document which).
- [ ] Full suite green; `cargo fmt --all -- --check` clean.
