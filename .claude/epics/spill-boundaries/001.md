# Task: Spill-covered native scan routing (scans feeding joins stream)

## Description

`PhysicalPlanner::collect_agg_covered_scans` marks only aggregate-covered
scans for `NativeStreamingScanExec`. Generalize to spill-covered: walk
the logical plan; a Scan is covered when every pipeline breaker on its
path to the root is spill-capable (Aggregate → SpillableHashAggregate,
Join → SpillableHashJoin on either side, Sort → ExternalSort) and no
materializing consumer (a bare projection/filter to the client, LIMIT
without a breaker, etc.) sits between. Keep the admission refusal for
uncovered shapes. Verify with the five queries that refuse today and
with `QE_DEBUG_SCAN_BUDGET`/plan traces that the streaming operator is
chosen.
