# Task: Python acceptance gate — pyarrow.flight TPC-H parity

## Description

`scripts/flight_validate.py` (run with `.venv/bin/python`), the epic's
acceptance gate from the PRD's user story 1 and 2:

- Connects to a node, runs all 22 TPC-H queries
  (source them the same way the existing oracle scripts do) via
  GetFlightInfo → DoGet.
- For each query, also POSTs the identical SQL to `/sql?format=arrow`
  and compares: cell-exact equality of the two Arrow results (sorted by
  all columns where the query has no ORDER BY, same convention as
  `validate_lance.py`).
- Asserts metadata parity per query: Flight metadata
  distributed/shards == HTTP x-qe-distributed/x-qe-shards.
- Modes: `--single` (spawn one `serve`, SF=0.01 and SF=0.1 data) and
  `--cluster` (expects `cluster_local.sh start 3`, runs the sweep
  against each of the 3 nodes).
- Wire into `cluster_local.sh verify` (cluster mode, one node, a
  reduced query set is acceptable for verify's runtime budget — full
  sweep stays a flag).
