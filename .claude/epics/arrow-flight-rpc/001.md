# Task: Add arrow-flight/tonic dependencies with add-only lock diff

## Description

Add `arrow-flight = "53"` (with the `flight-sql-experimental` feature OFF)
and `tonic = "0.12"` to Cargo.toml as regular (non-optional) dependencies.
Prove the addition cannot destabilize anything: the `Cargo.lock` diff must

once_cell 1.21.3.
