# Task: Rust integration tests for the Flight endpoint

## Description

`tests/flight_tests.rs`, using arrow-flight's client half against an
in-process `spawn()`ed server (pattern: existing
`tests/distributed_cluster.rs` in-process section, `data/tpch-1mb`):

- ListFlights lists the registered tables; GetSchema(lineitem) has 16
  fields matching the Parquet schema.
- GetFlightInfo(cmd) → DoGet round-trip for: a scan+filter, an
  aggregate (Q01 shape), a join (Q03 shape) — batches concatenated and
  compared cell-exact against `ctx.sql()` on the same data.
- Empty result (WHERE false) streams schema, zero rows, no error.
- Error statuses: syntax error → InvalidArgument, unknown table →
  NotFound, before-tables-loaded → Unavailable (spawn with a slow/failing
  loader to pin this).
- Ticket abuse: oversized ticket and malformed JSON ticket both →
  InvalidArgument, never a panic.
- `--flight-bind none` (ServeOptions with flight disabled): HTTP works,
  flight port closed.
- Extend `tests/distributed_cluster.rs`: in the existing 3-real-process
  gate, run one scatter query via Flight against each node and assert
  distributed:true + cross-node byte-equality.
