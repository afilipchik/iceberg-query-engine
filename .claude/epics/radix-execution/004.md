# Task: Radix high-NDV aggregation (morsel raw-sum path)

## Description

Q18's subquery (604M rows → 150M groups, key range ~600M) still runs
3.05s vs DuckDB 2.0s: thread-local raw-sum maps are far larger than LLC,
so every insert misses. Route high-NDV single-int-key shapes through
hash/range partitioning at ACCUMULATION time (each worker owns a
cache-sized key subset), finalizing through the existing
finalize_disjoint_states/merge machinery, which is already
correctness-pinned.
