# Task: Formal admission check for INSERT/CTAS write path

## Description

`create_table_as_select`/`insert_into_native_table`
(`src/execution/context.rs`) rely on `bounded_partition_merge`'s
concurrency cap (70% RSS reduction, but a 512MB cgroup cap still
SIGKILLs — the documented residual from native-tables-mutation task
005). Add a formal, named pre-flight admission check mirroring
`check_scan_budget`'s formula (`memory_limit * spill_threshold`) and
error style: refuse cleanly, by name, with exact byte counts, BEFORE
expensive work, when the estimated working set cannot fit (PRD G3).

Estimate = bounded by merge concurrency × per-partition working set
(row-group size × decode expansion), not source total size —
deliberately conservative but must not false-refuse the workloads that
already pass (SF=10/SF=100 appends at 1-2GB caps, measured 1.63-1.67GB
peaks).
