# Task: 2b-lite — deferred probe gather (Q9 ≤ 16s)

## Description

Q9's remaining ~11s vs DuckDB-parquet at SF=100 is probe-side gather:
`create_joined_batch` takes every output column through selection
indices at every join in the 3-join chain. Scoped 2b: for joins whose
parent is another join (keyed) or a fused aggregate (from 002), emit
(probe_row_id, build_row_id) + key columns only, gathering payload
columns once at the pipeline sink. NOT the engine-wide (batch, sel)
contract — just the join-chain path.

## Acceptance Criteria

- [ ] HJ_TIMING before/after showing gather time reduction on Q9's partsupp/orders probes
- [ ] Q9 SF=100 ≤ 16s (prior epic's unmet gate), no other query regresses >5%
- [ ] Row-id referential integrity tested: chained joins with duplicate matches, NULL keys, spill-path fallback (deferred mode must decline when a join spills)
- [ ] SF=10 + SF=100 cell-exact both formats; suites green both modes

## Technical Details

- `src/physical/operators/hash_join.rs` (`create_joined_batch`, probe
  loops) + planner wiring to mark defer-eligible joins.
- Pattern precedent: `GroupKeyReduction::try_defer_decorations` (unique
  aliases for id columns, referential integrity, JoinReorder
  interference — its recorded pitfalls apply).
- The build-side RowStore already exists (row-native join build) — late
  gather should read from it rather than re-concatenated Arrow arrays if
  cheaper; measure.
- Highest-risk task in the epic. Commit-or-revert; keep the lever behind
  a diagnostic env (`QE_DEFER_GATHER=0`) for A/B on the shipped binary.

## Outcome (2026-08-18) — negative result, residue named

Software prefetch on the VHT probe loops and row-store gather (the
latency-bound suspects) measured NEUTRAL on Q9 SF=100 wall (19.2-19.4s
vs 18.9-19.6 range) and on SF=10 — Q9 is CPU-SATURATION-bound: ~600s of
CPU across probes + aggregation workers + scans on 32 cores ≈ its 19s
wall, so hiding DRAM latency inside one stage moves nothing. Reverted
per commit-or-revert. The ≤16s gate requires reducing WORK: radix-
partitioned (cache-resident) join probes or selection-vector execution —
the program-level rewrite PARITY-PLAN 2b names. What DID move Q9 this
epic: dictionary-preserving gather (−2.8s parquet, −8.2s lance).
